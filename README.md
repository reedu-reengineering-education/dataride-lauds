# dataride-lauds
This repository brings together DATA-RIDE resources developed in Nancy through the LAUDS Factories programme, combining citizen-generated cycling data, participatory analysis and advocacy.

Graphics: Roll-up banner and event invitations.

LAUDS materials: Blueprint Canvas, project reports and final meeting poster materials.

Outcomes: Processed sensor data, Python scripts, processing methodology, maps in HTML and PDF formats, policy recommendations, the DATA-RIDE Toolkit and a project overview.

Photos: Visual documentation of project activities.

Presentations: Slides sharing the project process and findings.

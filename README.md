# LAUDS - DATA-RIDE
DATA-RIDE resources from the LAUDS Factories programme in Nancy: Blueprint, workshop presentations, campaign maps, policy recommendations, data-processing methodology, replication toolkit, posters, invitations and project photos. Together, they document citizen-generated cycling data, collective learning and advocacy for better cycling conditions.

--

The resources below guide users through assembling and setting up the DATA-RIDE senseBox:bike configuration with two lateral distance sensors, mounting it on a bicycle, configuring the application, and processing the collected data. They bring together the hardware guides, firmware, application and analysis scripts used in the Nancy campaign.

## Technology: Assembly, setup and data processing

1. **Prepare the enclosure:** access the [enclosure files](https://cloud.reedu.de/s/xwMSJnCnys7NBzR).

2. **Assemble the hardware:** follow the [assembly guide](https://github.com/reedu-reengineering-education/dataride-lauds/blob/main/DATA-RIDE%20-%20Assembly%20guide.pdf), including the required components, tools and connection instructions.

3. **Upload the firmware:** use the [Nancy dual-distance-sensor firmware](https://github.com/sensebox/senseBox-bike-Arduino/tree/main/senseBox-bike-nancy).

4. **Mount the device:** consult the [alternative mounting support guide](https://github.com/reedu-reengineering-education/dataride-lauds/blob/main/DATA-RIDE%20-%20Alternative%20Mounting%20Support.pdf) for the rear-rack mounting prototype, developed with support from Université de Lorraine and the Lorraine Fab Living Lab, Nancy.

5. **Set up the application:** consult the [senseBox:bike app repository](https://github.com/reedu-reengineering-education/sensebox-bike-flutter) for installation and configuration instructions.

6. **Collect and process data:** follow the [processing methodology](https://github.com/reedu-reengineering-education/dataride-lauds/blob/main/DATA_RIDE%20-%20Processing_methodology.pdf) and use the [data download, cleaning and overtaking-detection scripts](https://github.com/reedu-reengineering-education/dataride-lauds/tree/main/Data%20and%20Processing). Configure the required device identifiers locally before running the scripts.
